# Amad Asif Portfolio

Professional responsive portfolio website for Amad Asif, Software Engineer.

## Files

- `index.html` - Portfolio structure and content
- `style.css` - Responsive dark UI, typography, cards and animations
- `script.js` - Navigation, scroll state and reveal animations

## Deploy to GitHub Pages

1. Replace the files in your `amadasif-dev.github.io` repository with these files.
2. Commit and push to the `main` branch.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

The portfolio uses your public GitHub avatar and links to your GitHub and LinkedIn profiles.
